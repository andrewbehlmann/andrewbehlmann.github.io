Freditor

A light, fast WYSIWYG Markdown editor for macOS.

Features

  • Edit Markdown as formatted text, or switch to the raw Markdown source at any time (⌘E).
  • Word-style table picker (⌘T), headings, lists, task lists, quotes, code blocks and links.
  • Plain ⌘-key shortcuts throughout — no finger gymnastics.
  • Light and dark themes that follow your Mac, adjustable font and zoom.
  • Optional autosave, live line/word/character counts, rename files right from the toolbar.
  • Native Apple Silicon app. No account, no tracking, works offline.

Requirements

A Mac with Apple Silicon running macOS 13 Ventura or later.

Support

Questions, bug reports and feature requests are welcome: open an issue on GitHub. Please include your macOS version and, for bugs, the steps that cause the problem.

Privacy

Freditor collects no data. Read the privacy policy.
