Freditor

A light, fast WYSIWYG Markdown editor for macOS.

Features

  • Edit Markdown as formatted text, or switch to the raw Markdown source at any time (⌘E).
  • Word-style table picker (⌘T), headings, lists, task lists, quotes, code blocks and links.
  • Plain ⌘-key shortcuts throughout — no finger gymnastics.
  • Light and dark themes that follow your Mac, a font menu right in the toolbar, and zoom.
  • Print (⌘P), with a light page even in dark mode.
  • Optional autosave, live line/word/character counts, rename files right from the toolbar.
  • Native Apple Silicon app. No account, no tracking, works offline.

⌘/Keyboard shortcuts

In the table picker, use the mouse, or the arrow keys and Return. In a table, Tab and Shift-Tab move between cells, and Tab in the last cell adds a row. fn-Tab and fn-Shift-Tab indent and outdent list items, including lists inside table cells. Right-click inside a table to add or remove rows and columns. Numbered lists, task lists, code blocks and horizontal rules are in the toolbar and the Format menu.

Requirements

A Mac with Apple Silicon running macOS 13 Ventura or later.
